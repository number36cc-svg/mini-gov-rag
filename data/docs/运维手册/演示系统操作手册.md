# 政企统一缴费演示系统 操作手册（演示数据）

> 本文档为开源演示项目自编语料，所述系统为虚构演示系统，不对应任何真实产品。
> 版本：V2.1 ｜ 更新日期：2026-09

## 1. 登录与权限

1. 打开系统首页，输入统一分配的单位账号与初始密码
2. 首次登录强制修改密码：8-16 位，须含大写字母、小写字母、数字各一
3. 角色分为：单位管理员（可配置参数、管理经办人）、经办人（日常业务操作）、查询岗（只读）
4. 连续 5 次密码错误将锁定账号 30 分钟，解锁需单位管理员在"用户管理"中重置

## 2. 票据查询

1. 进入「票据管理 → 票据查询」
2. 查询条件支持：缴款人名称（模糊匹配）、缴款码、票据号码、缴款日期区间
3. 日期区间最长可查 1 年，跨年度查询请分年度检索
4. 查询结果单页显示 50 条，点击票据号码可查看票据明细并下载 PDF 版
5. 已冲销的票据在列表中以删除线显示，不可再下载

## 3. 缴费记录导出

1. 进入「缴费管理 → 记录导出」
2. 选择查询条件后点击「生成导出任务」，系统后台异步处理
3. 导出任务完成后在「导出记录」页下载，文件为加密压缩包，解压密码通过站内消息发送
4. 导出文件保留 7 天，过期自动清除，需重新生成

## 4. 参数配置（仅单位管理员）

1. 进入「系统设置 → 业务参数」
2. 可配置项包括：票据推送方式、导出条数上限、缴款提醒周期、对账单生成日
3. 参数修改实时生效，生效前系统会弹出二次确认，并记录操作日志
4. 涉及票据推送方式的变更，建议在非缴费高峰时段操作

## 5. 日常注意事项

- 系统每日 23:30 至次日 00:30 进行日终批处理，此期间暂停办理业务
- 批处理期间发起的请求会收到"系统日终处理中"提示，请在 00:30 后重试
- 遇到本手册未覆盖的提示信息，请参照本单位《常见报错对照》文档处理
