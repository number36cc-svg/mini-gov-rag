# 演示 GIF 录屏脚本（60-90 秒）

> 工具：macOS 自带 `Cmd+Shift+5` → 选"录制所选部分" → 框住整个浏览器窗口 → 录制。
> 目标：让面试官在 90 秒内看到"这系统真能跑、而且有别人没有的三件事"。
> **不要配音，不要鼠标乱晃**，动作慢而稳。

## 录制前准备（1 分钟）

```bash
# 三个终端窗口，或一个窗口开三个 tab：
cd /Users/zhangcong/WorkBuddy/2026-10-28-15-16-10/mini-gov-rag
.venv/bin/uvicorn app.main:app --port 8000     # ① API
.venv/bin/streamlit run app/ui.py              # ② 界面（会自动开浏览器）
```

浏览器窗口建议宽度 1200px 左右，缩放到 90%，让内容一屏可见。

## 分镜（按顺序，一镜到底，中途不剪）

**第 0-5 秒：开场定格**
界面加载完成，侧边栏能看到"知识库规模：288 切片"和服务状态。
（停顿 2 秒，让观众看清规模数字）

**第 5-25 秒：正常问答（绿标签 + 引用）**
在输入框问：

> 各级一般公共预算应当按照什么比例设置预备费？

等回答出现，**慢速向下滚动**展示：
1. 绿色"依据充分"标签
2. 回答正文里的比例数字"百分之一至百分之三"
3. 展开"依据条款"，显示《预算法》2018修正 第1页 的原文片段

**第 25-40 秒：超纲拒答（红标签）**
问：

> 预算法第 200 条规定了什么内容？

展示红色"无法回答"标签 + 拒答话术里的三条建议。
（这是全场最重要的一镜：证明系统不会编）

**第 40-60 秒：版本对比**
切换到"制度文件"场景，问：

> 2018 年修正相比 2014 年修正，非税收入管理相关条款有什么变化？

展示回答里明确写出两个版本的差异，引用里同时出现两个版本号。
如果模型回答不理想，改用：**"预算法第五十一条在两个版本里引用的条款号一样吗？"**（这题走结构化检索，稳）

**第 60-80 秒：场景切换 + 运维场景**
切到"运维手册"场景，问：

> B学院票据作废提示已实时推送须先红冲，怎么处理？

展示回答指向 B 学院特定规则——证明"多机构差异化知识"。

**第 80-90 秒：POC 报告收尾**
切到文件管理器打开 `reports/POC测试报告.md`，滚动展示：通过率、拒答正确率、逐条明细表格。
（用 Preview 或 VS Code 打开，字体放大到能看清）

## 录完处理

```bash
# 转 GIF 并压缩（需要 ffmpeg：brew install ffmpeg）
ffmpeg -i demo.mov -vf "fps=10,scale=1000:-1:flags=lanczos" -loop 0 docs/demo.gif
ls -lh docs/demo.gif    # 目标：10MB 以内
```

GIF 超过 10MB 的处理：`fps=8`、`scale=900:-1`，或者只保留前 60 秒（`-t 60`）。
